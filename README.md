# Smart Volume Discount – Yönlendirme sayfası

Shopify Admin’de uygulama linkine tıklanınca `?shop=...` ile bu sayfa açılır ve doğrudan **İndirim oluştur** formuna yönlendirir.

## GitHub Pages

1. Bu klasörü **ayrı bir repo** olarak push edin (sadece bu 3 dosya).
2. Repo **Settings** → **Pages** → **Source:** GitHub Actions.
3. `application_url`: `https://KULLANICI.github.io/REPO_ADI/`

Ana uygulama kodu (volume-discount-app) bu repo’da değildir; sadece yönlendirme sayfası.
